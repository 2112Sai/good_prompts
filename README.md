# My Prompt Library

A personal collection of reusable AI prompts, agent instructions,
and workflows developed through experimentation.

## Organization

- `prompts/` — Individual reusable prompts.
- `AGENTS.md` — Instructions for AI agents working with this repository.

## Using a prompt

1. Open the relevant prompt file.
2. Read its purpose and requirements.
3. Replace any placeholders with the relevant information.
4. Provide the prompt to your AI assistant or agent.

Not every prompt should be used at the same time.
Choose the prompt that matches the task.

## Status

This collection is a work in progress. Prompts may be revised as
I test them and improve the results.
